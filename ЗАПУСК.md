# Запуск приложения

## Структура проекта

```
для диплома/
├── backend/
│   ├── docker-compose.yml     # Единый Docker Compose
│   ├── api-gateway/           # API Gateway (порт 8000)
│   ├── services/
│   │   ├── user-service/      # порт 8001
│   │   ├── incident-service/  # порт 8002
│   │   ├── sla-service/       # порт 8003
│   │   └── notification-service/ # порт 8004
│   └── shared/                # Общий код (модели, БД, утилиты)
├── frontend/                  # Vue.js 3
└── ЗАПУСК.md
```

## БЫСТРЫЙ СТАРТ (Docker)

### Требования
- Docker Desktop (запущен)

### Запуск

```powershell
# 1. Перейти в папку backend
cd "C:\Users\User\Desktop\Общее\Диплом\для диплома\backend"

# 2. Запустить все сервисы
docker-compose up -d

# 3. Проверить статус
docker-compose ps

# 4. Создать администратора (первый запуск)
docker-compose exec user-service python -m shared.reset_admin
```

### Frontend (отдельно)

```powershell
cd "C:\Users\User\Desktop\Общее\Диплом\для диплома\frontend"
npm install
npm run dev
```

### Адреса
- Frontend: http://localhost:5173
- API Gateway: http://localhost:8000
- Swagger UI: http://localhost:8000/docs
- User Service: http://localhost:8001/docs
- Incident Service: http://localhost:8002/docs

### Учетные данные по умолчанию

## Локальный запуск (без Docker)

### Требования
- Python 3.12+
- Node.js 18+
- PostgreSQL 14+
- Redis

### 1. База данных

```powershell
# Создать БД в psql
psql -U postgres
CREATE DATABASE incidents_db;
\q
```

### 2. Backend

```powershell
cd "C:\Users\User\Desktop\Общее\Диплом\для диплома\backend"

# Создать venv
python -m venv venv
.\venv\Scripts\activate

# Установить зависимости
pip install -r api-gateway/requirements.txt
pip install -r services/user-service/requirements.txt
pip install -r services/incident-service/requirements.txt
pip install -r services/sla-service/requirements.txt
pip install -r services/notification-service/requirements.txt

# Инициализация БД
python -m shared.init_db

# Создать администратора
python -m shared.reset_admin
```

### 3. Запуск сервисов (5 терминалов)

```powershell
# Активировать venv в каждом терминале
cd backend
.\venv\Scripts\activate

# Терминал 1: User Service
cd services/user-service
uvicorn main:app --host 0.0.0.0 --port 8001 --reload

# Терминал 2: Incident Service
cd services/incident-service
uvicorn main:app --host 0.0.0.0 --port 8002 --reload

# Терминал 3: SLA Service
cd services/sla-service
uvicorn main:app --host 0.0.0.0 --port 8003 --reload

# Терминал 4: Notification Service
cd services/notification-service
uvicorn main:app --host 0.0.0.0 --port 8004 --reload

# Терминал 5: API Gateway
cd api-gateway
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 4. Frontend

```powershell
cd "C:\Users\User\Desktop\Общее\Диплом\для диплома\frontend"
npm install
npm run dev
```

## Частые проблемы

### 1. "Port already in use"

```powershell
# Найти процесс на порту
netstat -ano | findstr :8000

# Завершить процесс
taskkill /PID <pid> /F
```

### 2. Docker контейнеры не стартуют

```powershell
# Посмотреть логи
docker-compose logs api-gateway
docker-compose logs user-service

# Пересобрать
docker-compose up -d --build
```

### 3. "Module not found" (локальный запуск)

```powershell
# Проверить, что venv активирован
.\venv\Scripts\activate

# Переустановить зависимости
pip install -r services/user-service/requirements.txt
```

### 4. Ошибка подключения к БД

```powershell
# Проверить, что PostgreSQL запущен
# Проверить строку подключения в .env:
# DATABASE_URL=postgresql+asyncpg://postgres:password@localhost:5432/incidents_db
```

### 5. Frontend не подключается к API

Проверить, что API Gateway запущен на порту 8000:
```powershell
curl http://localhost:8000/health
```

### 6. Docker volumes конфликтуют

```powershell
# Полная очистка
docker-compose down -v
docker system prune -f
docker-compose up -d --build
```
